05ClaudeCodeUsage

Built for Claude Code — sessions, tokens, cache & costConçu pour Claude Code — sessions, tokens, cache et coût專為 Claude Code 打造——工作階段、token、快取與成本

Your Claude Code usage, visible at a glance.Votre usage de Claude Code, visible d'un coup d'œil.你的 Claude Code 用量，一眼看完。

Claude Code quietly writes usage data to local transcripts on every turn. ClaudeCodeUsage turns that into a dashboard you can actually read — sessions, turns, tokens, prompt cache and estimated cost, filterable by model and date range, with a daily usage chart.Claude Code écrit discrètement des données d'usage dans des transcripts locaux à chaque tour. ClaudeCodeUsage en fait un tableau de bord réellement lisible — sessions, tours, tokens, cache de prompt et coût estimé, filtrables par modèle et par période, avec un graphique d'usage quotidien.Claude Code 每一輪都會默默把用量寫進本機的 transcript。ClaudeCodeUsage 把這些資料變成一個真正讀得懂的儀表板——工作階段、輪次、token、prompt 快取與估計成本，可依模型與時間範圍篩選，並附每日用量圖表。

Everything Claude Code tracks, made visibleTout ce que Claude Code enregistre, rendu visible把 Claude Code 記錄的一切，變成看得見的

A tiny native app that reads the JSONL transcripts Claude Code already writes to ~/.claude/projects, and turns them into a dashboard.Une petite app native qui lit les transcripts JSONL que Claude Code écrit déjà dans ~/.claude/projects, et en fait un tableau de bord.一個小巧的原生應用程式，讀取 Claude Code 本來就會寫進 ~/.claude/projects 的 JSONL transcript，並把它們變成儀表板。

  • Local & privateLocal et privé本機且私密

    Reads your local transcripts only. Nothing is ever uploaded — the app has no network calls beyond checking for its own updates.Lit uniquement vos transcripts locaux. Rien n'est jamais envoyé — l'app ne fait aucun appel réseau au-delà de la vérification de ses propres mises à jour.只讀取你本機的 transcript。任何資料都不會上傳——除了檢查自身更新之外，這個應用程式沒有任何網路連線。

  • Daily usage chartGraphique d'usage quotidien每日用量圖表

    A stacked chart of input, output, cache read and cache creation tokens, per day.Un graphique empilé des tokens d'entrée, de sortie, de lecture et de création de cache, par jour.以堆疊圖呈現每日的輸入、輸出、快取讀取與快取建立 token。

  • Estimated costCoût estimé估計成本

    Approximate USD cost per model family, computed from your actual token usage.Coût approximatif en USD par famille de modèle, calculé à partir de votre usage réel de tokens.依模型家族估算的美元成本，根據你實際的 token 用量計算。

  • Model & date filtersFiltres par modèle et par date模型與日期篩選

    Slice by model — Opus, Sonnet, Haiku — and by range: today, this week, 30d, 90d, all time.Découpez par modèle — Opus, Sonnet, Haiku — et par période : aujourd'hui, cette semaine, 30 j, 90 j, depuis le début.依模型切分——Opus、Sonnet、Haiku——也可依範圍切分：今天、本週、30 天、90 天、全部。

  • Auto-refreshRafraîchissement automatique自動更新

    Rescans every 30 seconds, incrementally — only newly appended transcript bytes are read.Rescanne toutes les 30 secondes, de façon incrémentale — seuls les octets ajoutés aux transcripts sont relus.每 30 秒增量重新掃描——只讀取 transcript 新追加的位元組。

  • Native SwiftUISwiftUI natif原生 SwiftUI

    A small, fast, native macOS app — no Electron, no background daemon.Une app macOS native, petite et rapide — sans Electron, sans démon en arrière-plan.小巧快速的原生 macOS 應用程式——不用 Electron，也沒有背景常駐程式。

What you actually seeCe que vous voyez vraiment你實際會看到的畫面

The real dashboard — sessions and cost trends, automatic insights, model mix, and the daily usage chart — plus the editable pricing sheet.Le vrai tableau de bord — tendances de sessions et de coût, insights automatiques, répartition par modèle et graphique d'usage quotidien — plus la feuille de tarifs éditable.真實的儀表板——工作階段與成本趨勢、自動洞察、模型組成，以及每日用量圖表——外加可編輯的費率表。

Numbers Claude Code already has, finally visibleDes chiffres que Claude Code a déjà, enfin visiblesClaude Code 早就有的數字，終於看得見

Claude Code logs token usage on every turn, but there's no built-in way to see the totals. ClaudeCodeUsage sits read-only on top of those transcripts — across every local project — so your sessions, tokens and estimated spend become a single glanceable dashboard.Claude Code enregistre l'usage de tokens à chaque tour, mais rien n'est prévu pour en voir les totaux. ClaudeCodeUsage se pose en lecture seule au-dessus de ces transcripts — sur tous vos projets locaux — pour réunir sessions, tokens et dépense estimée dans un seul tableau de bord.Claude Code 每一輪都會記錄 token 用量，卻沒有內建的方式看到總計。ClaudeCodeUsage 以唯讀方式架在這些 transcript 之上——涵蓋所有本機專案——把工作階段、token 與估計花費彙整成單一、一眼可讀的儀表板。

  • Read-onlyLecture seule唯讀

    Never writes to Claude Code's dataN'écrit jamais dans les données de Claude Code永不寫入 Claude Code 的資料

  • All projectsTous les projets所有專案

    Aggregates usage across every local repoAgrège l'usage de tous les repos locaux彙整所有本機版本庫的用量

  • IncrementalIncrémental增量

    Only re-reads appended transcript bytesNe relit que les octets ajoutés aux transcripts只重讀 transcript 新追加的位元組

  • NativeNatif原生

Up and running in a minuteOpérationnel en une minute一分鐘內開始使用

ClaudeCodeUsage reads the transcripts Claude Code already writes locally — there's nothing else to configure.ClaudeCodeUsage lit les transcripts que Claude Code écrit déjà en local — il n'y a rien d'autre à configurer.ClaudeCodeUsage 讀取 Claude Code 本來就會寫在本機的 transcript——沒有別的要設定。

  1. Have Claude Code installed. ClaudeCodeUsage visualizes its local usage data, so use Claude Code at least once first.Avoir Claude Code installé. ClaudeCodeUsage visualise ses données d'usage locales : utilisez Claude Code au moins une fois d'abord.先安裝 Claude Code。ClaudeCodeUsage 視覺化的是它在本機的用量資料，所以請先至少使用一次 Claude Code。

  2. Download & install. Grab the latest .dmg and drag ClaudeCodeUsage.app into /Applications.Télécharger et installer. Récupérez le dernier .dmg et glissez ClaudeCodeUsage.app dans /Applications.下載並安裝。取得最新的 .dmg，把 ClaudeCodeUsage.app 拖入 /Applications。

  3. Launch. Open it — your usage dashboard populates from your local transcripts within a few seconds.Lancer. Ouvrez-la — votre tableau de bord se remplit depuis vos transcripts locaux en quelques secondes.啟動。開啟它——幾秒內就會從你本機的 transcript 填滿用量儀表板。
